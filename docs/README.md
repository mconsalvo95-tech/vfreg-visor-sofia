# Documentation

Operator instructions are **not** in this folder. They ship inside the factory
ZIP from `portable/` (`LEEME-EMPRESA.txt`, `GUIA-OPERADOR-INICIO-AUTOMATICO.txt`).

| Path | Who it is for |
|---|---|
| `dev/` | Developers and support: remaining work, notebook setup, session handoff |
| `mockups/` | Approved UI mockup for later comparison. Not in the factory ZIP. |
| `DATA_INTEGRITY_AND_RECOVERY.md` | Backup and restore notes for support |

Released product changes go in the root `CHANGELOG.md`. That file is the history
of what shipped. The roadmap in `dev/` is the remaining work plan. They stay
separate so operators never have to open a phase checklist.
